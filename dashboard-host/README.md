# Dashboard Host Application

Dashboard host application demonstrating integration of `@rtc-widget/react` with `platformId="platform-test1"`.

## 🚀 Running the App

```bash
cd dashboard-host
npm install
npm run dev
```

## ⚙️ Configuration

- **`platformId`**: `"platform-test1"` (Shares platform scope with `demo-host-app`).
- **`currentUser`**: `user-1` ("Admin 1", role: `"admin"`).
- **`serverUrl`**: `http://localhost:5000`.
