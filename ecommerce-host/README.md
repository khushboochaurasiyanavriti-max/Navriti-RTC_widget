# E-Commerce Host Application

Store operations host application demonstrating integration of `@rtc-widget/react` with isolated platform `platformId="ecommerce-platform"`.

## 🚀 Running the App

```bash
cd ecommerce-host
npm install
npm run dev
```

## ⚙️ Configuration

- **`platformId`**: `"ecommerce-platform"` (Isolated from `platform-test1` and `platform-test2`).
- **`currentUser`**: `user-14` ("Khushboo14").
- **`serverUrl`**: `http://localhost:5000`.
