# Demo Host Application

Sample host application demonstrating integration of `@rtc-widget/react` with `platformId="platform-test1"`.

## 🚀 Running the App

```bash
cd demo-host-app
npm install
npm run dev
```

The application runs on `http://localhost:5173`.

## ⚙️ Configuration

- **`platformId`**: `"platform-test1"` (Shares platform scope with `dashboard-host`).
- **`currentUser`**: `user-8` ("Khushboo").
- **`serverUrl`**: `http://localhost:5000`.
